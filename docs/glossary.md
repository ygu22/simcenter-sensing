Working definitions of terms used across this repo.

## Sessions, runs, subjects

- **Session** — one continuous data-collection event for one subject/team unit.
- **Run** — an optional segment within a session (e.g., scenario 1, scenario 2).
- **Subject** — one consented individual.
- **Team** — a set of subjects analyzed as a unit.

## Modalities

- **Computer vision (CV)** — Camera-based extraction of pose, face, gaze
  direction, location, and movement.
- **Physiology** — Wearable sensors capturing autonomic-nervous-system signals
  (HR, HRV, EDA, temperature, accelerometry, respiration, etc.).
- **Eye tracking** — Gaze direction and fixation, typically via wearable Tobii
  glasses.
- **Communication analysis** — Speech, language, and turn-taking from audio
  and transcripts.

## Processing terms

- **Sync marker** — A deliberate, multimodal-detectable event used to align clocks.
- **Drift** — Accumulating offset between a device clock and the canonical clock.
- **Synchrony** — A statistical relationship between time series across
  individuals (physiological, behavioral, etc.).
